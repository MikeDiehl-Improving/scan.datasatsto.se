scan.datasatsto.se

This service exposes the following API endpoints. Enter values and run a call directly from this page.

View the database stored procedure reference

MethodPathDescription
GET/new/:eventRegister a new identity and generate its QR code for the given event.

            
GET/new/:event/:idRegister using a specific existing ID (for integrations).

            
GET/setupConfigure the scanning client's vendor code, or look up the codes for an ID.

            
POST/setupSave the vendor code to the session.

            
GET / POST/:id/:codeRecord a scan for the given ID and vendor code.

            
GET/:idRecord a scan for the given ID (no vendor code).

            
GET/report/:secretView the scan report for an event, identified by its secret.

            
GET/random/:secretView one random scan for an event.

            
GET/random/:secret/:codeView one random scan for an event, filtered by vendor code.

            
GET/pdf/:secretShow the form to generate a PDF badge/report.

            
POST/pdfGenerate the PDF document.

            
GET/expireExpire old events and remove their cached QR codes.
