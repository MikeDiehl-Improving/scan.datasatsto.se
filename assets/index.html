scan.datasatsto.se

This service exposes the following API endpoints. Enter values and run a call directly from this page.

View the database stored procedure reference

MethodPathDescription
GET/new/:eventRegister a new identity and generate its QR code for the given event.

            
GET/new/:event/:idRegister using a specific existing ID (for integrations).

            
GET/setupConfigure the scanning client's vendor code, or look up the vendor codes for an ID.

            
POST/setupSave the vendor code to the session.

            
GET / POST/:id/:vendorCodeRecord a scan for the given ID and vendor code.

            
GET/:idRecord a scan for the given ID (no vendor code).

            
GET/report/:eventView the scan report for an event, identified by its event ID.

            
GET/random/:eventView one random scan for an event.

            
GET/random/:event/:vendorCodeView one random scan for an event, filtered by vendor code.

            
GET/pdfOpen the interactive form to generate a PDF badge/report.

            
GET/authorization-pdfPrint the organizer scanner authorization QR code for an event.

            
GET/expireExpire old events and remove their cached QR codes.
